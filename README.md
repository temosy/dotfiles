# dotfiles

Personal dotfiles and macOS setup notes.

## Repository map

- `.vimrc` keeps the Vim configuration.
- `.tmux.conf` keeps the tmux configuration.
- `config.fish` keeps the fish shell configuration.
- `nix-darwin/` keeps the nix-darwin and Home Manager configuration.
- `zsh/.zshrc.generated` is a generated zsh snapshot for reference.
- `update.sh` refreshes tracked files from the current machine.

## Nix managed macOS setup

The current macOS environment is managed with nix-darwin and Home Manager.

- `nix-darwin/flake.nix` manages system packages and macOS defaults.
- `nix-darwin/home.nix` manages user packages, zsh, Home Manager files, and user launchd agents.
- `nix-darwin/flake.lock` pins the Nix inputs.

Apply the configuration with:

```sh
sudo darwin-rebuild switch --flake ~/projects/dotfiles/nix-darwin
```

Build without applying:

```sh
darwin-rebuild build --flake ~/projects/dotfiles/nix-darwin
```

## zsh

`~/.zshrc` is generated by Home Manager from `nix-darwin/home.nix`.

`zsh/.zshrc.generated` is only a snapshot of the generated file for reference. Edit zsh behavior in `nix-darwin/home.nix`, then run `darwin-rebuild switch`.

## GitHub and Zed

GitHub authentication for Git is handled by GitHub CLI over HTTPS. `nix-darwin/home.nix` installs `gh` and configures Git to use `gh auth git-credential` for `github.com` and `gist.github.com`.

Zed uses the local Git configuration for Git operations. `core.editor` is set to `zeditor --wait` because the Nix package exposes the Zed CLI as `zeditor`.

## Updating this repository from the current machine

Before running the update script, make sure the local machine has the source
files in place:

- `~/.vimrc`
- `~/.tmux.conf`
- `~/.config/fish/config.fish`
- `~/.config/nix-darwin/flake.nix`
- `~/.config/nix-darwin/home.nix`
- `~/.config/nix-darwin/flake.lock`
- `~/.zshrc`

Run:

```sh
./update.sh
```

This copies the current vim, tmux, fish, nix-darwin, and generated zsh files into the repository.

Review the copied changes before committing:

```sh
git diff
```
